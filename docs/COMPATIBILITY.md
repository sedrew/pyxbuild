## Notes

* **torch** needs the Visual C++ runtime (`msvcp140.dll`,
  `msvcp140_atomic_wait.dll`, `vcruntime140_threads.dll`), which neither
  Windows nor python-build-standalone ships; `pyxbuild doctor` reports this
  before the app is run. Adding `msvc-runtime` to the dependencies puts the
  DLLs next to `python.exe`. The remaining failure under Wine is Wine's
  (`GetNumaNodeProcessorMaskEx` is not implemented, OpenMP needs it); the
  `torch + msvc-runtime` app is run on real Windows by the CI golden job
  (`tests/golden/level3`).
* **uvloop** does not support Windows at all; the build stops at resolution
  with a hint instead of producing a broken app.
* Sizes are the unpacked application folder (runtime ≈ 44 MB of it).
* Earlier failures fixed by this run: statsmodels (bug in the smoke test,
  float compared with `==`), torch on 3.11 (python-build-standalone 3.11
  preinstalls setuptools, which clashed with torch's own; the bundle now
  starts from an empty `site-packages`).
